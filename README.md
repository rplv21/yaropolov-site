# yaropolov.ru

Сайт-визитка интернет-маркетолога. Astro + vanilla JS, деплой на Vercel.
Содержание и NDA-ограничения зафиксированы в [PROMPT_yaropolov_site.md](../PROMPT_yaropolov_site.md)
и в [src/data/site.ts](./src/data/site.ts).

## Команды

| Команда           | Действие                                    |
| :----------------- | :------------------------------------------- |
| `npm install`       | Установка зависимостей                       |
| `npm run dev`       | Локальный сервер на `localhost:4321`         |
| `npm run build`     | Сборка в `./dist/`                           |
| `npm run preview`   | Просмотр собранной версии                    |
| `npx astro check`   | Проверка типов                               |

## Переменные окружения

Форма заявки отправляет сообщения в Telegram через `src/pages/api/send-lead.ts`.
Скопируйте `.env.example` в `.env` и заполните:

```
TELEGRAM_BOT_TOKEN=  # токен @YaropolovPbot от BotFather
TELEGRAM_CHAT_ID=    # ID чата, куда бот шлёт заявки
```

Токен и chat_id никогда не должны попадать в репозиторий — `.env` в `.gitignore`.
На проде эти же переменные задаются в Vercel → Settings → Environment Variables.

## Что нужно сделать перед публикацией

1. Задать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в Vercel.
2. Вставить ID Яндекс.Метрики в `src/layouts/Layout.astro` (сейчас закомментирован
   плейсхолдер `REPLACE_WITH_METRIKA_ID`) и настроить цели: отправка формы,
   клик по телефону/Telegram/ВК, завершение расчёта в калькуляторе.
3. Проверить `/privacy` и при необходимости — вопрос об уведомлении
   Роскомнадзора (см. раздел 7 мастер-промпта) у юриста.
4. Прогнать Lighthouse / PageSpeed на проде и свериться с целевыми
   показателями (LCP < 2.0с, CLS < 0.1, INP < 200мс).

## Структура

- `src/data/site.ts` — единственный источник контента (контакты, кейсы,
  услуги, FAQ). Любые изменения цифр или формулировок проверять на
  соответствие ограничениям из раздела 0 мастер-промпта.
- `src/components/` — секции лендинга и визуальные эффекты (стекло,
  частицы, анимированные графики, фоновые pie-чарты).
- `src/pages/api/send-lead.ts` — serverless-функция приёма заявок.
